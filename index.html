Resume Tailor

Four-agent pipeline that produces a gap analysis, targeted rewrite suggestions, a cover letter, and interview prep questions from a resume + job description - without fabricating experience. An Analyzer agent extracts matched/missing keywords and computes an ATS score (deterministic formula, not an opaque LLM number), then hands off to dedicated Rewrite, Cover Letter, and Interview Prep agents. All LLM calls are provider-agnostic via a single client file.
